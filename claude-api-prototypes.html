Your API usage has dropped

Your Claude API usage over the past 30 days is well below where it was the month before. If that was deliberate, nothing needs to happen and you can ignore this.

If it was not, the causes below account for most of the drops we see. Each one links to the guide that walks through it.

Common reasons usage stops
Your credit balance ran out
Requests are refused once the balance reaches zero, and a workflow can stop mid-run without anyone noticing. Auto-reload prevents it.
Set up auto-reload and spend alerts
You were hitting rate limits or overload errors
Repeated 429 or 529 responses will stall a job. Retries with backoff, or a higher usage tier, usually clear it.
Read about rate limits and retries
A model you depended on was retired
Pinned model versions are eventually deprecated. Calls to a retired version fail rather than falling back.
Check the model deprecation schedule
It cost more than you expected
Prompt caching cuts input cost on repeated prefixes, the Batch API halves the price of anything not time-sensitive, and Haiku handles high-volume classification for a fraction of Sonnet.
See ways to reduce cost
Your integration broke after a change
Schema changes, tool definitions and SDK upgrades are the usual culprits when a workflow that ran for months suddenly stops.
Read the API changelog and versioning guide
You moved the workload to a cloud provider
If your traffic now runs through Amazon Bedrock, Google Vertex AI or Microsoft Foundry, this drop is expected and nothing is wrong.
Compare direct API and cloud platform access
Read the troubleshooting guide
